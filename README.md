# Gladi8or Labs LLC

The public website for Gladi8or Labs LLC. This is a lightweight static site built with HTML and CSS; it does not require a build step or external packages.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Publish with GitHub Pages

In the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save. GitHub Pages will publish the site from the repository root.

The company logo is in `assets/gladi8or-icon.png`. The Couch Combat tile currently uses a temporary CSS icon; replace it with the app icon when it is available.

The Contact Us form opens the visitor's default email app with a prefilled message to `admin@gladi8orlabs.app`; visitors review and send the email themselves. Add the Buy Me a Coffee profile URL when it is available.
